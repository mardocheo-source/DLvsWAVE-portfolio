# Attribution and reuse

This portfolio is made available for technical inspection of the work represented in this repository. The original source tree did not contain a repository-wide LICENSE/COPYING/NOTICE file or an explicit general reuse grant. This preparation does not invent one. Public visibility is not a substitute for an explicit software license; contact the repository owner for reuse permission where needed.

Dependencies such as NumPy, SciPy, scikit-learn, PyTorch, PyKAN, pandas, Astropy and Astroquery are external projects with their own authors and licenses. They are referenced/installed, not vendored or relicensed here. See their upstream distributions and license files. No dependency environment or library source tree is bundled.

Data rights are separate from software rights. The download/processing code and synthetic benchmark outputs are included; raw scientific databases, caches, figures and imported geographic assets are not. Source-specific attribution and the explicit exclusions are documented in [PORTFOLIO_DATA_SOURCES.md](PORTFOLIO_DATA_SOURCES.md).

The project citation in the README identifies the GitHub author handle and this preparation's actual version tag. It is a software/portfolio citation, not a peer-reviewed scientific publication or DOI claim.
